# Contributing

Thanks for following along! This repo backs the Skills in Action YouTube tutorials, so it changes mostly when a new episode ships. Contributions that help most:

- **A tutorial step doesn't work for you?** Open a [bug in a tutorial](https://github.com/skillsinaction/skills-in-action/issues/new/choose) issue with the episode, the step number, the command, the full error, your OS, and `node -v` / `claude --version` / `codex --version`.
- **Want a skill or an episode?** Open a [request a skill](https://github.com/skillsinaction/skills-in-action/issues/new/choose) issue and describe the job you keep explaining to your agent.
- **Pull requests** are welcome for typos, broken links, and fixes for newer tool versions. Keep each PR small and say what you tested. For a new skill, please open an issue first.

Rules of thumb:
- No secrets, tokens or personal data in issues, logs or PRs.
- Results in this repo are reported as measured; please don't edit numbers without new runs and the data behind them.
- Be kind. Everyone here is learning.
